# Changelog

## 1.0.0

- 103 engineering decision records in 13 categories, with implementation guidance, verification checks and source references.
- Build and Audit workflows for new and existing projects, with 16 on-demand engineering standards.
- Local English and Turkish search with SQLite FTS5 and a CLI. The optional read-only MCP server also exposes all 16 standards and the Build, Audit and operating guidance on demand.
- Skill installation guides for Codex, Claude Code, Cursor, Gemini CLI and OpenCode, including AI-assisted, CLI-managed and manual setup.
- Runnable music shuffle, reservation, payment retry and cursor pagination examples. The localized READMEs show shuffle results and a checkout walkthrough in Markdown.
- Eight localized READMEs with setup, examples, FAQ and roadmap. The complete Skill Directory links directly to each canonical record.
- A contribution guide in eight languages and an accessibility policy with a link to report barriers.
- A 74-query retrieval regression and optional paired discovery and implementation benchmarks. Discovery can use the installed skill or a local MCP server.
